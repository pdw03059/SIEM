# stage1 — 학습용 프로토타입 (MAZKION 엔진 아님)

이 폴더는 프로젝트 착수 전, "로그를 받아 저장하고 찾는다"는 가장 기본 흐름을 C로 익히기 위한 **학습용 예제**입니다.
- 수신: UDP 시스로그를 받아 날짜별 파일에 그대로 추가 저장
- 조회: 날짜 범위의 파일을 처음부터 끝까지 읽으며 키워드를 찾음(**색인 없음, 순차 검색**)

MAZKION 본 엔진은 이 방식이 아닙니다. 본 엔진 설계(docs/ARCHITECTURE.md, 0단계)와 구현(A·B단계)에는 다음이 들어갑니다.
- 테이블별 쓰기 큐와 시간 파티션, 세그먼트 단위 저장
- 역인덱스(키워드 → 위치), 세그먼트별 블룸 필터(없는 키워드는 파일을 열지 않음)
- 필드별 컬럼 저장과 압축, IP·사용자 같은 필드 색인
- 쿼리 계획기(시간·조건을 먼저 적용해 읽을 범위를 줄임), CPU 코어 병렬 처리, 여러 노드 분산 검색
- 메모리 예산 안에서 동작하는 캐시(GC 없음)
본 엔진의 성능 목표는 docs/PLAN.md 5장을 따릅니다: 단일 x86 서버 UDP 수집·저장·인덱싱 540만 EPS 이상, 노드당 600GB/일 이상(검색 부하 동시 처리), 25억 건 이상 검색은 동일 조건 기준 응답 시간의 1/2 이하. 이 stage1 프로토타입은 색인 없는 순차 검색 예제이므로 성능 목표의 근거나 벤치마크로 사용하지 않습니다. 시험 기준은 docs/BENCHMARK_PLAN.md를 따릅니다.
